Jarvis Public — Project Summary
================================

Location: C:\Users\xkosiekpcwin\jarvis-public\
Original (private): C:\Users\xkosiekpcwin\jarvis\
Purpose: Sanitized, sellable version of Jarvis — local AI voice assistant (Iron Man style) for Windows 11.

What It Does
-------------
Wake word ("Hey Jarvis") → STT (Whisper) → LLM (multi-provider) → TTS (Kokoro) → follow-up loop.
Web UI at localhost:7860. 31 tools: screen vision/OCR, desktop automation, web search, file ops, code exec, app control (30+ apps), and more.

Stack
------
- Python 3.12, virtualenv, FastAPI + WebSocket + uvicorn
- STT: faster-whisper (tiny/small/medium/large-v3, CPU or CUDA)
- TTS: Kokoro-82M (local CPU)
- Wake word: openWakeWord with custom hey_jarvis_v0.1.onnx
- LLM: Ollama (default), any OpenAI-compatible provider addable via web UI
- Vision/OCR: PyAutoGUI + Pillow screenshots → Windows PowerShell OCR
- Memory: SQLite + ChromaDB for fact storage

REST APIs (web.py)
-------------------
GET    /api/providers          — list all providers with full details
POST   /api/providers/{key}    — set active provider
PUT    /api/providers/{key}    — add/update provider
DELETE /api/providers/{key}    — delete provider (can't delete active)
GET    /api/settings           — all config (tts, stt, wake_word, llm temp, tools)
PUT    /api/settings           — partial update any settings section
GET    /api/mute               — get mute state
POST   /api/mute               — toggle mute
WebSocket /ws                  — real-time events (chat, interrupt, tool calls, responses)

Web UI Features (index.html)
------------------------------
- Iron Man HUD design: Orbitron/Rajdhani fonts, arc reactor SVG animation, floating particles, scan lines, cyan/gold/deep blue palette
- 4 side panel tabs: Tools (tool call log), Live (event feed), Actions (8 quick command buttons), Config (full settings)

- Controls: Provider dropdown in header, mute button, abort button, stop command (voice or typed)

Abort System
-------------
- Esc key → abort_all() → stops TTS + tool loop + LLM calls
- Voice "stop" → detected after transcription, triggers abort (works in wake and follow-up)
- Web "stop" → typed in chat, triggers abort
- Web ABORT button → sends interrupt via WebSocket
- WebSocket handler catches _Aborted gracefully (no ASGI crashes)
